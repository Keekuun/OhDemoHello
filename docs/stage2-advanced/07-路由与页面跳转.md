# 07 路由与页面跳转

> 学习目标：学会从一个页面跳到另一个页面，还能带数据过去。

## 一、两种导航方式

| 方式 | 适合 | 项目例子 |
|------|------|----------|
| **Tabs** | 几个平级主页面，底部切换 | 首页/发现/消息/组件/我的 |
| **router 路由** | 从主页跳进详情页，带返回箭头 | 我的 → 关于我们 |

本项目是「Tabs 装主页面 + router 跳二级页面」的混合结构，这是最常见的主流结构。

## 二、router 三件套

```typescript
import { router } from '@kit.ArkUI';

// ① 跳过去（新页面压上来，能返回）
router.pushUrl({ url: 'pages/AboutPage' });

// ② 返回上一页
router.back();

// ③ 替换当前页（当前页被销毁，返回时跳过它，适合登录页）
router.replaceUrl({ url: 'pages/Index' });
```

## 三、带参数跳转

跳过去时带点数据，比如「详情页」要知道显示哪条内容：

```typescript
// 出发页：带参数
router.pushUrl({
  url: 'pages/DetailPage',
  params: { title: '好消息', desc: '这是详细内容' }
});

// 到达页：接参数（在 aboutToAppear 里）
aboutToAppear(): void {
  const params = router.getParams() as Record<string, string>;
  if (params?.title) {
    this.title = params.title;
  }
}
```

项目实例：`DetailPage.ets`（看它的 `aboutToAppear`）、`AboutPage.ets` 跳 `LegalPage` 时传了 `type` 参数区分隐私政策还是服务协议。

## 四、新页面三步走（必背流程）

假设要加一个「设置页」：

**第 1 步**：建文件 `entry/src/main/ets/pages/SettingsPage.ets`
```typescript
@Entry
@Component
struct SettingsPage {
  build() {
    Column() {
      Text('设置').fontSize(24)
    }
  }
}
```

**第 2 步**：注册路由 `entry/src/main/resources/base/profile/main_pages.json`
```json
{ "src": [ ..., "pages/SettingsPage" ] }
```

**第 3 步**：加个入口（比如我的页面菜单）
```typescript
router.pushUrl({ url: 'pages/SettingsPage' });
```

**少第 2 步，跳转必失败**——这是新手最常踩的坑，再强调一次。

## 五、页面顶部的返回栏（项目标准写法）

每个二级页面顶部都有一个返回栏，看 `AboutPage.ets` 的写法：

```typescript
Row() {
  SymbolGlyph($r('sys.symbol.chevron_left'))   // 左箭头图标
    .fontSize(24)
    .onClick(() => { router.back(); })          // 点它返回

  Text('页面标题')
    .fontSize(18)
    .fontWeight(FontWeight.Bold)
}
.width('100%')
.height(56 + this.statusBarHeight)              // 高度要加上状态栏
.padding({ left: 16, right: 16, top: this.statusBarHeight })  // 顶部留出状态栏
```

> 为什么 `top: this.statusBarHeight`？因为 App 是沉浸式的，内容会顶到屏幕最顶上，不躲开会被时间、电量图标盖住。第 13 篇会详细讲。

## 六、页面栈（理解跳转的本质）

页面像一摞盘子：

```
push  AboutPage   →  [Index, AboutPage]     最上面的是当前页
push  LegalPage   →  [Index, AboutPage, LegalPage]
back              →  [Index, AboutPage]     弹掉最上面的
```

`router.getLength()` 能看当前摞了几层。

## 动手练

1. 新建一个「收藏页」`FavoritesPage.ets`，走完「三步走」流程，从「我的 → 我的收藏」点进去。
2. 给收藏页传一个参数（比如收藏数量），在页面里显示出来。

## 小结

- 跳页 `router.pushUrl`，返回 `router.back()`，传参用 `params` + `router.getParams()`
- 新页面三件事：建文件 → 注册 `main_pages.json` → 加入口
- 二级页面记得做返回栏，并给状态栏留高度
