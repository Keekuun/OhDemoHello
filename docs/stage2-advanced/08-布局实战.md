# 08 布局实战

> 学习目标：看到任何设计图，都能拆成 Column/Row/Stack 拼出来。

## 一、三大容器（记住这三个就够日常用）

```
Column（竖排）      Row（横排）        Stack（层叠）
┌─────────┐       ┌───┬───┬───┐      ┌─────────┐
│  元素1  │       │ 1 │ 2 │ 3 │      │ 元素2   │
├─────────┤       └───┴───┴───┘      │  ┌───┐  │
│  元素2  │                          │  │ 1 │  │
├─────────┤                          └──┼───┼──┘
│  元素3  │                             └───┘
└─────────┘                          后写的压在上面
```

## 二、尺寸与间距

```typescript
Column() {
  Text('内容')
}
.width('100%')              // 宽度：100% 撑满父容器 / 200 固定值 / '50%'
.height(200)                // 高度
.padding({                  // 内边距（边框到内容的距离）
  left: 16, right: 16,
  top: 12, bottom: 12
})
.margin({ top: 16 })        // 外边距（自己和别人的距离）
.borderRadius(16)           // 圆角
.backgroundColor(Color.White)
```

**padding vs margin 分不清？** 想象一个快递盒：
- `padding` = 盒子里面的泡沫填充（内容离盒壁的距离）
- `margin` = 盒子和别的盒子之间留的空隙

## 三、对齐方式

```typescript
Column() {
  Text('A')
  Text('B')
}
.alignItems(HorizontalAlign.Start)   // 横向：靠左（Column 里是控制横向）
.justifyContent(FlexAlign.Center)    // 纵向：居中（主轴方向）

Row() {
  Text('A')
  Text('B')
}
.alignItems(VerticalAlign.Center)    // 纵向：居中（Row 里是控制纵向）
.justifyContent(FlexAlign.SpaceBetween)  // 横向：两端分开
```

**记忆法**：
- `justifyContent` 管「主轴」（Column 的主轴是竖的，Row 的主轴是横的）
- `alignItems` 管「交叉轴」（跟主轴垂直的那个方向）

常用值：`Start` `Center` `End` `SpaceBetween`（两端对齐）`SpaceEvenly`（均匀分布）。

## 四、layoutWeight：瓜分剩余空间

```typescript
Row() {
  Text('左').width(80)              // 固定 80
  Text('中').layoutWeight(1)        // 吃掉所有剩余空间
  Text('右').width(80)              // 固定 80
}
```

项目实例：`ProfilePage.ets` 菜单行的文字用 `.layoutWeight(1)`，把箭头挤到最右边。

## 五、实战拆解：一张「用户信息卡」怎么写

设计图：左边圆形头像，中间两行字（名字+ID），右边一个按钮。

**拆解思路**：
```
Row（最外层横排）
 ├── 头像（Column 画个圆）
 └── Column（中间竖排两行字，layoutWeight(1) 占满中间）
 │    ├── Text（名字）
 │    └── Text（ID）
 └── Text（右边按钮）
```

对应代码（就是 `ProfilePage.ets` 里的 `ProfileHeader`）：

```typescript
Row() {
  // 头像：一个 72x72 的圆
  Column() {
    Text('H').fontSize(36).fontColor(Color.White)
  }
  .width(72).height(72)
  .borderRadius(36)                          // 半径=宽度一半 → 圆形
  .linearGradient({ angle: 135, colors: [...] })  // 渐变底色
  .justifyContent(FlexAlign.Center)

  // 中间文字区
  Column() {
    Text('鸿蒙开发者').fontSize(20).fontWeight(FontWeight.Bold)
    Text('ID: 88888888').fontSize(13)
  }
  .alignItems(HorizontalAlign.Start)   // 文字靠左
  .layoutWeight(1)                     // 占满中间
  .margin({ left: 16 })

  Text('···').fontSize(24)
}
.width('100%')
.alignItems(VerticalAlign.Center)      // 整行垂直居中
.padding(20)
.borderRadius(16)
.backgroundColor(Color.White)
.shadow({ radius: 6, color: 'rgba(0,0,0,0.06)', offsetY: 2 })  // 阴影
```

## 六、卡片样式模板（万能公式）

项目里所有卡片都是这个配方：

```typescript
.width('100%')
.padding(16)                    // 里面留空
.borderRadius(16)               // 圆角
.backgroundColor($r('app.color.card_background'))  // 白底
.margin({ top: 16 })            // 和上面卡片隔开
.shadow({ radius: 6, color: 'rgba(0,0,0,0.06)', offsetX: 0, offsetY: 2 })  // 淡阴影
```

## 七、滚动：内容超出屏幕怎么办

```typescript
Scroll() {
  Column() {
    // ...很多内容
  }
}
.scrollBar(BarState.Off)          // 隐藏滚动条
.edgeEffect(EdgeEffect.Spring)    // 拉到底有回弹效果
.layoutWeight(1)                  // 占满剩余高度
```

注意：`Scroll` 里只能放**一个**子组件，所以里面先套个 `Column`。

## 小结

- 竖排 Column、横排 Row、层叠 Stack，万物皆可拆
- 对齐记口诀：`justifyContent` 管主轴，`alignItems` 管交叉轴
- `layoutWeight(1)` 瓜分剩余空间，`Blank()` 把元素顶开
- 卡片 = 白底 + 圆角 16 + 淡阴影 + 内边距 16
