# 05 常用组件大全

> 学习目标：认识做 App 最常用的「积木块」，知道什么效果用什么组件。
> 本项目的 `ComponentsPage.ets` 就是一本活的组件字典，对照着看。

## 二、最常用的 5 个（先精通这几个）

### 1. Text —— 显示文字
```typescript
Text($r('app.string.app_title'))
  .fontSize(20)                          // 字号
  .fontWeight(FontWeight.Bold)           // 加粗
  .fontColor($r('app.color.text_primary')) // 颜色
  .maxLines(1)                           // 最多 1 行
  .textOverflow({ overflow: TextOverflow.Ellipsis })  // 超出显示...
```

### 2. Button —— 按钮
```typescript
Button('提交', { type: ButtonType.Capsule })  // 胶囊形
  .width('100%')
  .height(48)
  .backgroundColor($r('app.color.primary_color'))
  .onClick(() => {
    // 点击后干嘛
  })
```

### 3. TextInput —— 输入框
```typescript
@State inputText: string = '';

TextInput({ placeholder: '请输入', text: this.inputText })
  .onChange((value: string) => {
    this.inputText = value;   // 用户每敲一个字，这里就收到最新内容
  })
```
项目实例：`FeedbackPage.ets` 的反馈输入框。

### 4. List —— 长列表
```typescript
List() {
  ForEach(this.dataList, (item: string) => {
    ListItem() {
      Text(item)
    }
  })
}
```
**数据多少条，列表就多少行**。项目实例：`MessagePage.ets` 的消息列表、`ListPage.ets`。

### 5. Tabs —— 底部/顶部标签页
项目首页 `Index.ets` 就是标准写法：
```typescript
Tabs({ barPosition: BarPosition.End }) {   // 标签栏在底部
  TabContent() { HomePage() }.tabBar('首页')
  TabContent() { ProfilePage() }.tabBar('我的')
}
```

## 三、ForEach：循环生成组件

有一组数据，想每个数据显示成一个组件？用 `ForEach`：

```typescript
@State fruits: string[] = ['苹果', '香蕉', '橘子'];

Column() {
  ForEach(this.fruits, (fruit: string, index: number) => {
    Text(`${index + 1}. ${fruit}`).fontSize(16)
  }, (fruit: string) => fruit)   // 第三个参数：给每项一个唯一标识
}
```
数组从 3 个变 5 个，界面自动多 2 行——又是「数据驱动」。

## 四、if 条件渲染

```typescript
if (this.isVip) {
  Text('尊贵的会员').fontColor(Color.Orange)
} else {
  Text('普通用户')
}
```
`isVip` 一变，显示的内容自动切换。项目实例：`ProfilePage.ets` 里角标 `badge` 的显示。

## 五、Blank：弹簧空白

`Row` 里想把右边的元素顶到最右边？中间塞个 `Blank()`：
```typescript
Row() {
  Text('左边')
  Blank()          // 吃掉所有多余空间
  Text('右边')     // 被顶到最右
}
```

## 动手练

1. 打开 `ComponentsPage.ets`，找到开关 `Toggle`，把它的打开颜色改成你喜欢的颜色。
2. 在任意页面用 `ForEach` 显示你的 3 个爱好。

## 小结

- 记组件不用背：先记住 Text/Button/Input/List/Tabs 五个，其他用到再查
- `ForEach` 循环渲染、`if` 条件渲染，是拼界面的两大法宝
- 不知道某个组件有什么属性？在 DevEco 里输入组件名后按 `.`，自动提示全列出来
