# 03 声明式 UI 思维

> 学习目标：理解鸿蒙画界面的核心思想——**描述「要什么」，而不是「怎么做」**。

## 一、两种思维对比

**命令式**（老式写法）：一步步指挥
```
1. 创建一个文本框
2. 设置文字为"你好"
3. 设置字号 20
4. 把它加到页面上
5. 数据变了？再手动找到它，改文字
```

**声明式**（鸿蒙 ArkUI）：直接描述结果
```typescript
Text('你好').fontSize(20)
```
数据变了？**界面自己跟着变**，不用你管。

类比：命令式像自己下厨每一步都动手；声明式像点菜——你只说「我要什么」，厨房（系统）帮你做。

## 二、build() 里描述界面

每个组件都有一个 `build()` 方法，里面就是界面的「设计图」：

```typescript
@Entry
@Component
struct Index {
  build() {
    Column() {                    // 竖排容器
      Text('标题')                 // 一行字
        .fontSize(24)             // 字号
        .fontWeight(FontWeight.Bold)  // 加粗
      Button('点我')               // 一个按钮
        .onClick(() => {          // 点它干嘛
          console.log('被点了');
        })
    }
    .width('100%')                // 容器宽度撑满
    .height('100%')
  }
}
```

读法口诀：**大括号 `{}` 里装内容，点 `.` 后面挂属性**。

## 三、链式调用（. 一直点下去）

```typescript
Text('你好')
  .fontSize(16)              // 字号
  .fontColor(Color.Red)      // 颜色
  .margin({ top: 10 })       // 外边距
  .padding({ left: 8 })      // 内边距
```

每个 `.xxx()` 都是给这个组件加一个样式或行为，顺序无所谓，随便换。

## 四、数据驱动界面（最重要的一句话）

看 `Index.ets` 的 Tab 栏逻辑：

```typescript
@State currentTabIndex: number = 0;   // ① 有个状态变量

// Tab 图标颜色：选中就蓝色，没选中就灰色
.fontColor(this.currentTabIndex === index
  ? $r('app.color.primary_color')
  : $r('app.color.text_hint'))
```

当 `currentTabIndex` 从 0 变成 1：
1. 你不用手动去改图标颜色
2. 系统发现 `@State` 变量变了
3. **自动重新执行相关界面代码**，颜色自己就变了

这就是「数据驱动」：**你只管改数据，界面是数据的「影子」**。

## 五、组件套组件（积木思维）

界面是层层套出来的：

```
Column（竖排）
 ├── Text（标题）
 ├── Row（横排）
 │    ├── Image（图）
 │    └── Text（字）
 └── Button（按钮）
```

打开 `ProfilePage.ets` 看看，它的「用户信息卡」就是 `Column` 套 `Row` 再套 `Text`，像俄罗斯套娃。

## 六、@Builder：把重复的 UI 抽出来

同一个页面里，好几段 UI 长得一样？抽成 `@Builder` 函数复用：

```typescript
@Builder
StatItem(value: string, label: ResourceStr) {
  Column() {
    Text(value).fontSize(22).fontWeight(FontWeight.Bold)
    Text(label).fontSize(13)
  }
}

// 用三次，生成三个长得一样的统计格子：
this.StatItem('128', '动态')
this.StatItem('5.2万', '粉丝')
this.StatItem('326', '关注')
```

## 动手练

1. 打开 `entry/src/main/ets/pages/HomePage.ets`，找到任意一个 `Text`，给它加一句 `.fontColor(Color.Red)`，用 Previewer 看效果。
2. 把某个 `Column()` 改成 `Row()`，观察里面的内容从竖排变横排。

## 小结

- 声明式 = 描述要什么，系统帮你做
- `build()` 是设计图，`{}` 装内容，`.` 挂属性
- **改数据 → 界面自动变**，这是 ArkUI 的核心
- 重复的 UI 用 `@Builder` 抽出来复用
