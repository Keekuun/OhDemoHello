# 04 看懂项目结构

> 学习目标：知道每类文件放在哪、管什么用，改东西不迷路。

## 一、整体地图

```
OhDemoHello/
├── AppScope/                  ← 整个 App 的「身份证」
│   ├── app.json5              ← 包名、版本号、图标、名称
│   └── resources/             ← 全局资源（应用名、图标）
│
├── entry/                     ← 主模块（代码都在这）
│   └── src/main/
│       ├── ets/               ← ArkTS 源码（你天天改的地方）
│       │   ├── entryability/  ← App 启动入口
│       │   └── pages/         ← 所有页面（30+ 个）
│       ├── resources/         ← 模块资源（文字/颜色/图片）
│       │   ├── base/          ← 默认（浅色）资源
│       │   ├── dark/          ← 深色模式资源
│       │   └── rawfile/       ← 原封不动打包的文件
│       └── module.json5       ← 模块配置（权限、页面注册）
│
├── docs/                      ← 你正在看的学习文档
├── build-profile.json5        ← 项目级构建配置（SDK 版本等）
└── oh-package.json5           ← 依赖清单（像购物清单）
```

## 二、四个关键配置文件

### 1. `AppScope/app.json5` —— App 的身份证
```json5
{
  "app": {
    "bundleName": "com.example.ohdemohello",  // 包名，全球唯一
    "versionCode": 1000000,                    // 内部版本号（数字）
    "versionName": "1.0.0",                    // 给用户看的版本号
    "icon": "$media:layered_image",            // 桌面图标
    "label": "$string:app_name"                // 桌面名称
  }
}
```

### 2. `entry/src/main/module.json5` —— 模块的说明书
管三件事：
- **权限声明** `requestPermissions`：要用相机、定位，先在这登记
- **页面注册** `"pages": "$profile:main_pages"`：指向页面清单
- **入口能力** `abilities`：App 从哪个 Ability 启动

### 3. `entry/src/main/resources/base/profile/main_pages.json` —— 页面花名册
```json
{ "src": ["pages/Index", "pages/AboutPage", ...] }
```
**新建页面必须在这注册，否则跳转时找不到！** 这是新手最常踩的坑。

### 4. `oh-package.json5` —— 依赖清单
```json5
{ "devDependencies": { "@ohos/hypium": "1.0.25" } }
```
要用别人的库，在这登记，工具自动下载到 `oh_modules/`。

## 三、资源引用：$r() 是什么

代码里你会看到大量 `$r('app.string.xxx')`、`$r('app.color.xxx')`：

| 写法 | 引用的文件 | 作用 |
|------|-----------|------|
| `$r('app.string.app_title')` | `resources/base/element/string.json` | 取一段文字 |
| `$r('app.color.primary_color')` | `resources/base/element/color.json` | 取一个颜色 |
| `$r('app.media.startIcon')` | `resources/base/media/startIcon.png` | 取一张图 |
| `$r('sys.symbol.house')` | 系统自带 | 取系统图标 |

**为什么不直接写 `'鸿蒙百宝箱'`？** 因为资源文件支持多语言、深色模式自动切换——写死就切换不了了。

## 四、代码从哪开始跑（启动流程）

```
点桌面图标
  → module.json5 找到 EntryAbility
  → EntryAbility.ets 的 onWindowStageCreate()
  → 设置全屏沉浸式、记录状态栏高度
  → loadContent('pages/Index') 加载首页
  → Index.ets 的 build() 画出 5 个 Tab
```

打开 `entry/src/main/ets/entryability/EntryAbility.ets`，对照上面的流程看一遍代码。

## 五、哪些文件夹别手动改

| 目录 | 原因 |
|------|------|
| `oh_modules/` | 依赖包，自动下载的 |
| `entry/build/` | 编译产物，每次构建自动重新生成 |
| `.hvigor/` | 构建工具的缓存 |

这些已在 `.gitignore` 里排除，不用管。

## 动手练

1. 在 `main_pages.json` 里找到 `pages/AboutPage`，再去 `pages/` 目录找到对应文件，体会「注册 → 文件」的对应关系。
2. 打开 `string.json`，随便加一个字符串 `{ "name": "my_test", "value": "测试" }`，然后在某个页面里用 `$r('app.string.my_test')` 显示出来。

## 小结

- 代码在 `entry/src/main/ets/`，资源在 `resources/`，配置在两个 `json5`
- 新页面三件事：建文件 → `main_pages.json` 注册 → 加跳转入口
- 文字/颜色/图片都走 `$r()` 引用资源，别写死
