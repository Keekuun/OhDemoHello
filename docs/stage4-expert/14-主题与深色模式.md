# 14 主题与深色模式

> 学习目标：让 App 跟随系统切换深色模式，还能做自定义主题色。
> 项目实例：`resources/dark/` 目录、`ThemePage.ets`

## 一、深色模式的原理（一句话）

系统在「设置 → 显示 → 深色模式」一切换，你的 App 自动换一套颜色——**前提是你的颜色都走资源文件，没写死**。

## 二、鸿蒙的资源替换机制

```
resources/
├── base/element/color.json    ← 默认（浅色）颜色
└── dark/element/color.json    ← 深色模式颜色
```

两个文件里**同名的颜色**，系统根据当前模式自动选：

```json
// base/element/color.json（浅色）
{ "name": "page_background", "value": "#F1F3F5" }   // 浅灰底

// dark/element/color.json（深色）
{ "name": "page_background", "value": "#1A1A1A" }   // 深灰底
```

代码里始终写 `$r('app.color.page_background')`，**系统帮你选值，一行代码都不用改**。

## 三、为什么千万别写死颜色

```typescript
// ❌ 写死：深色模式下白底白字，瞎了
Text('你好').fontColor('#182431').backgroundColor('#FFFFFF')

// ✅ 走资源：自动跟随模式
Text('你好').fontColor($r('app.color.text_primary')).backgroundColor($r('app.color.card_background'))
```

**检查自己项目的方法**：全局搜 `#`，看有没有颜色值写死在 `.ets` 文件里。

## 四、手动控制深色模式

`EntryAbility.ets` 里这行决定 App 跟不跟随系统：

```typescript
this.context.getApplicationContext().setColorMode(
  ConfigurationConstant.ColorMode.COLOR_MODE_NOT_SET   // 跟随系统
  // COLOR_MODE_DARK   强制深色
  // COLOR_MODE_LIGHT  强制浅色
);
```

做一个「设置页里的深色模式开关」：

```typescript
Toggle({ isOn: this.isDark })
  .onChange((isOn: boolean) => {
    getContext(this).getApplicationContext().setColorMode(
      isOn ? ConfigurationConstant.ColorMode.COLOR_MODE_DARK
           : ConfigurationConstant.ColorMode.COLOR_MODE_LIGHT
    );
    // 用 Preferences 存起来，下次启动时读取（复习第 10 篇）
  })
```

## 五、自定义主题色（进阶）

想让用户选「蓝色主题 / 绿色主题」？思路：

1. 把主题色存进 `AppStorage`：
```typescript
AppStorage.setOrCreate('themeColor', '#007DFF');
```

2. 组件里绑定：
```typescript
@StorageLink('themeColor') themeColor: string = '#007DFF';

Button('按钮').backgroundColor(this.themeColor)
```

3. 用户一点「换绿色」，改 `AppStorage` 的值，**所有绑定的地方自动变色**（又是数据驱动）。

> 注意：`@StorageLink` 是双向的，改它会写回 AppStorage；`@StorageProp` 是只读的。

## 六、深色模式适配检查清单

- [ ] 所有颜色走 `color.json`，dark 目录有对应深色值
- [ ] 图片在深色下看得清（必要时准备深色版图片）
- [ ] 阴影在深色下要减弱或去掉（黑底上看不出阴影）
- [ ] 亲自开系统深色模式，把每个页面过一遍

## 动手练

1. 打开手机/模拟器的深色模式，观察本项目哪些页面适配好、哪些有问题。
2. 给 `color.json` 加一个新颜色 `brand_color`，浅色深蓝、深色浅蓝，然后在某个按钮上用它。
3. 在「我的」页加一个主题色切换入口，实现蓝色/绿色主题互换。

## 小结

- 深色模式 = 同名颜色资源，base 和 dark 各一份，系统自动选
- 颜色写死是万恶之源，一律走 `$r()`
- 自定义主题色 = AppStorage 存色值 + `@StorageLink` 绑定
