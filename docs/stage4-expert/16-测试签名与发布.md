# 16 测试、签名与发布

> 学习目标：给代码上保险（测试），把 App 打包成能上架的安装包。

## 一、为什么要写测试

手动点一遍能发现问题，但改代码后**旧功能可能悄悄坏掉**（这叫「回归」）。
测试就是写一批「自动检查员」，每次改完代码让它们跑一遍，坏了立刻报警。

## 二、单元测试（Hypium）

本项目已配好测试框架 `hypium`，测试文件在 `entry/src/ohosTest/` 目录。

一个测试长这样：

```typescript
import { describe, it, expect } from '@ohos/hypium';

// 被测的函数
function add(a: number, b: number): number {
  return a + b;
}

export default function mathTest() {
  describe('数学函数测试', () => {           // describe：一组测试
    it('加法应该正确', 0, () => {           // it：一个具体测试
      expect(add(1, 2)).assertEqual(3);     // expect：断言结果
      expect(add(-1, 1)).assertEqual(0);
    });

    it('边界情况', 0, () => {
      expect(add(0, 0)).assertEqual(0);
    });
  });
}
```

**三段式口诀**：
- `describe` 分组：「我要测哪块功能」
- `it` 用例：「具体测什么场景」
- `expect(...).assertXxx(...)` 断言：「结果应该是这样」

**该测什么**：工具函数、数据转换、表单校验逻辑——这些「输入确定、输出确定」的纯逻辑最好测。界面点击类测试用 UI 测试框架（UiTest），入门阶段先不写。

## 三、签名：给 App 盖公章

鸿蒙要求每个 App 必须「签名」才能安装——证明「这 App 真是你发的，没被篡改」。

开发时 DevEco Studio 可以**自动签名**：
`File → Project Structure → Signing Configs` → 勾选 `Automatically generate signature`，登录华为账号，它帮你搞定一切。

正式发布要手动申请：
1. 去 [华为开发者联盟](https://developer.huawei.com) 实名认证（个人开发者要身份证）
2. 生成私钥和证书请求文件（DevEco 里有向导）
3. 在开发者联盟申请**发布证书**和 **Profile 文件**
4. 在 `Signing Configs` 里配置发布签名

> 开发阶段用自动签名就够了，要上架才需要折腾发布证书。

## 四、打包：生成安装包

菜单 `Build → Build Hap(s)/App(s) → Build App(s)`：

| 产物 | 用途 |
|------|------|
| `.hap` | 单个模块的安装包，开发调试用 |
| `.app` | 完整应用包，**上架应用市场要的就是它** |

打包前检查清单：
- [ ] `app.json5` 里 `versionCode` 比上次大（商店要求每次递增）
- [ ] `versionName` 写对用户可见的版本号（如 1.1.0）
- [ ] 用**发布证书**签名（不是自动签名）
- [ ] 深色模式、不同尺寸设备都测过
- [ ] 隐私政策、用户协议已上线（商店审核必查）

## 五、上架华为应用市场

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/)
2. 「我的应用」→ 新建应用 → 填名称、分类、图标、截图
3. 上传 `.app` 包
4. 填隐私政策网址、权限用途说明
5. 提交审核，一般 1~3 个工作日出结果

**常见被拒原因**：
- 权限申请和实际功能不符（复习第 11 篇：权限最小化）
- 没有隐私政策
- 有闪退、明显 bug
- 图标/截图侵权

## 六、发布后的持续维护

```
用户反馈 bug → 修复 → versionCode +1 → 重新打包 → 提交更新
```

AppGallery Connect 后台能看：下载量、崩溃报告、用户评价。**崩溃报告要天天看**，那是真实用户帮你找到的 bug。

## 动手练

1. 给项目里的某个工具函数写一个单元测试（比如字符串格式化函数），跑一遍看全绿。
2. 用自动签名打一个 debug 包，装到真机上。
3. 模拟一次版本更新：把 `versionCode` 改成 1000001，`versionName` 改成 1.0.1，重新打包。

## 小结

- 测试 = 自动检查员，改代码后跑一遍防回归
- 签名 = 公章，开发用自动签名，上架用发布证书
- 上架四件套：`.app` 包 + 隐私政策 + 截图 + 权限说明
- 发布后盯崩溃报告和用户评价
