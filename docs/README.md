# 鸿蒙开发学习路线（从入门到深入）

> 这套文档配合本项目「鸿蒙百宝箱 OhDemo」的真实代码来讲解。
> 学每一篇时，建议打开对应的页面文件，**边看、边改、边跑**，效果最好。

## 你是谁，这套文档适合谁

- 完全没做过鸿蒙开发，甚至没怎么写过代码
- 想系统学会 HarmonyOS（鸿蒙）App 开发
- 手里已经有这个项目，想知道每一行代码是干嘛的

## 怎么用这套文档

1. **按顺序学**。每篇都假设你已经会了前面的内容。
2. **每篇都有「动手练」**。一定要亲手改代码、跑起来看效果，只看不动手等于没学。
3. **遇到报错别慌**。把报错信息完整复制下来，问 AI 或查官方文档。
4. **项目里的每个页面都是例子**。文档里会告诉你「去看哪个文件」。
