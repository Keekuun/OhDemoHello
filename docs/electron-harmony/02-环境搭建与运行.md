# 02 环境搭建与运行

> 学习目标：把鸿蒙 Electron 工程跑起来。推荐用**预编译包**路线，半天搞定；源码编译是硬核路线，8 小时起步。

## 一、两条路线对比

| 路线 | 耗时 | 适合 |
|------|------|------|
| **A. 预编译包**（推荐） | 约 1 小时 | 99% 的开发者 |
| B. 源码编译 | 约 1 天（编译 8 小时） | 需要改 Electron 底层的人 |

## 二、路线 A：预编译包（推荐）

### 第 1 步：准备工具

- [ ] DevEco Studio（最新版，5.x）
- [ ] 华为开发者账号（下载预编译包、签名都要用）
- [ ] 鸿蒙 PC 设备或模拟器（**手机不行**）
- [ ] Node.js 16+（本地开发 Electron 应用用）

### 第 2 步：下载预编译包

1. 用华为账号登录 Electron HarmonyOS 发布仓库（官方 DevCloud 发布页，从 [openharmony-sig/electron](https://gitcode.com/openharmony-sig/electron) 仓库说明进入）。
2. 选 **Electron 37**（最新稳定版）的最新日期产物，zip 约 200~300MB。
3. 解压，得到 `ohos_hap` 工程。

### 第 3 步：认识工程结构

```
ohos_hap/
├── AppScope/                     # 应用级配置（图标、名称）
├── electron/                     # Electron 主模块
│   ├── libs/arm64-v8a/           # ★ 核心原生库
│   │   ├── libelectron.so        #   Electron 引擎（150~200MB）
│   │   ├── libadapter.so         #   鸿蒙适配层
│   │   ├── libffmpeg.so          #   多媒体
│   │   └── libc++_shared.so      #   C++ 运行时（来自鸿蒙 SDK）
│   └── src/main/module.json5     # 窗口尺寸等配置
└── web_engine/                   # Web 引擎模块（HSP）
    └── src/main/
        ├── module.json5          # ★ 权限声明在这里
        └── resources/resfile/
            ├── resources.pak     # Chromium 资源文件
            ├── icudtl.dat
            └── resources/app/    # ★★ 你的 Electron 代码放这里！
                ├── main.js       #   主进程入口（必需）
                ├── package.json  #   应用配置（必需）
                ├── index.html    #   界面
                └── ...           #   其他前端文件
```

**检查清单**：`electron/libs/arm64-v8a/` 下 4 个 `.so` 必须都在，缺一个就起不来。

### 第 4 步：放入你的应用代码

把你的 Electron 应用（或编译产物）放进：
```
web_engine/src/main/resources/resfile/resources/app/
```

> 注意：如果项目用 TypeScript / Vue / React，要**先编译成纯 JS/HTML** 再放进来——运行时没有构建工具。

### 第 5 步：配置签名（必须，否则装不上）

`File → Project Structure → Signing Configs` → 勾选自动签名 → 登录华为账号。

### 第 6 步：运行

1. USB 连接鸿蒙 PC（开开发者模式），或启动 2in1 模拟器
2. 点 ▶️ Run，等编译、签名、安装完成
3. 应用启动后，按 **Ctrl + Alt + I** 可打开 DevTools 调试

命令行安装方式（备选）：
```bash
hdc app install electron-default-signed.hap
```

## 三、路线 B：源码编译（硬核）

仅当你需要修改 Electron 底层时才走这条路。

**环境要求**：Ubuntu 22.04（实体机或虚拟机）、git-lfs、ccache、Node 20.18.1。

```bash
# 1. 克隆适配仓库
git clone -b master https://gitcode.com/openharmony-sig/electron.git
git lfs pull                      # 大文件必须拉全，否则 .so 只有 130 字节

# 2. 拉取鸿蒙版 Chromium（repo 多仓管理）
cd electron
repo init -u https://gitcode.com/openharmony-tpc/manifest.git -b pc_chromium_132 -m pc_chromium_132_20251106.xml --no-repo-verify
repo sync -c                      # 网不好就多跑几次
repo forall -c 'git lfs pull'

# 3. 应用鸿蒙补丁
pushd src && find -name "*.git*" -exec rm -rf "{}" \; && popd
chmod +x override_files.sh && ./override_files.sh

# 4. 装编译依赖（仅首次）
sudo ./src/build/install-build-deps.sh --no-chromeos-fonts

# 5. 编译（8 核机器约 8 小时）
./electron_build.sh
```

产物在 `src/out/musl_64/`：`libelectron.so`、`libadapter.so`、`libffmpeg.so`、`*.pak`、`icudtl.dat` 等，拷进 `ohos_hap` 工程对应位置即可。

> 常见坑：`override_files.sh` 网络不稳会漏拉 `rust-toolchain.tar.gz`，先备份再执行。

## 四、定制你的应用

| 改什么 | 改哪里 |
|--------|--------|
| 应用名称 | `electron/src/main/resources/zh_CN/element/string.json` 的 `EntryAbility_label` |
| 应用图标 | `AppScope/resources/base/media/` |
| 首窗口尺寸 | `electron/src/main/module.json5` 的 abilities → metadata（width/height） |
| 权限 | `web_engine/src/main/module.json5` 的 `requestPermissions` |
| 多实例开关 | 不需要多实例就删掉 `multiAppMode` 配置 |

## 五、权限说明（常用）

| 权限 | 用途 | 必要性 |
|------|------|--------|
| `INTERNET` / `GET_NETWORK_INFO` | 联网 | 基础 |
| `RUNNING_LOCK` | 后台持续运行 | 基础 |
| `READ_PASTEBOARD` | 读剪贴板 | 基础 |
| `PREPARE_APP_TERMINATE` | 关闭前执行清理 | 基础 |
| `FILE_ACCESS_PERSIST` | 持久化文件访问 | 基础 |
| `READ_WRITE_DOWNLOAD/DOCUMENTS/DESKTOP_DIRECTORY` | 访问公共目录 | 按需 |
| `CAMERA` / `MICROPHONE` / `LOCATION` | 硬件能力 | 按需 |
| `SYSTEM_FLOAT_WINDOW` / `WINDOW_TOPMOST` | 悬浮窗/置顶 | 按需（需 ACL 签名） |

> ⚠️ 部分权限（如 `SYSTEM_FLOAT_WINDOW`、`READ_PASTEBOARD`）属于 **ACL 受限权限**，需要向华为申请证书才能签名通过。申请不下来时，先把这些权限**注释掉**保证能跑。

## 小结

- 预编译包路线：下载 → 代码放进 `resources/app/` → 签名 → Run
- 4 个 `.so` 库必须齐、必须签名、必须是 2in1 设备
- 源码编译只给需要改底层的人，Ubuntu 22.04 + 8 小时
