# 09 网络请求与数据

> 学习目标：让 App 联网拿数据——比如从服务器拉一篇文章列表。
> 项目实例：`NetworkPage.ets`

## 一、联网前的准备：声明权限

App 想联网，必须先在 `module.json5` 里登记（本项目已登记好）：

```json5
"requestPermissions": [
  {
    "name": "ohos.permission.INTERNET",
    "reason": "$string:perm_internet_reason",
    "usedScene": { "abilities": ["EntryAbility"], "when": "always" }
  }
]
```

`INTERNET` 是「普通权限」，登记了就能用，不用弹窗问用户。相机、定位那种「敏感权限」才需要弹窗（见第 11 篇）。

## 二、发一个 GET 请求（最简流程）

```typescript
import { http } from '@kit.NetworkKit';

// 创建一个请求对象
const request = http.createHttp();

request.request(
  'https://api.example.com/articles',   // 接口地址
  {
    method: http.RequestMethod.GET,      // 请求方式
    connectTimeout: 10000,               // 连接超时 10 秒
    readTimeout: 10000                   // 读取超时 10 秒
  }
).then((response) => {
  if (response.responseCode === 200) {
    // 成功！response.result 是服务器返回的字符串
    const data = JSON.parse(response.result as string);
    console.info('拿到数据：' + JSON.stringify(data));
  }
}).catch((err: Error) => {
  // 失败：断网、地址错了、服务器挂了都会进这里
  console.error('请求失败：' + err.message);
}).finally(() => {
  request.destroy();   // 用完销毁，好习惯
});
```

## 三、async/await 写法（推荐，更好读）

上面 `.then().catch()` 的链式写法容易绕晕，换成同步写法：

```typescript
async function loadData(): Promise<void> {
  const request = http.createHttp();
  try {
    const response = await request.request('https://api.example.com/articles');
    if (response.responseCode === 200) {
      const data = JSON.parse(response.result as string);
      // 处理数据
    }
  } catch (err) {
    console.error('请求失败', err);
  } finally {
    request.destroy();
  }
}
```

**`async`/`await` 的意思**：`await` 让代码「等这一步做完再走下一步」，像排队一样，逻辑从上往下读，符合直觉。

## 四、把数据显示到界面上

完整闭环：**请求 → 存进 @State → 界面自动刷新**

```typescript
@Entry
@Component
struct ArticlePage {
  @State articles: string[] = [];
  @State loading: boolean = true;

  aboutToAppear(): void {
    this.loadArticles();   // 页面一出现就去拉数据
  }

  async loadArticles(): Promise<void> {
    const request = http.createHttp();
    try {
      const res = await request.request('https://api.example.com/articles');
      const data = JSON.parse(res.result as string);
      this.articles = data.list;        // ① 数据塞进 @State
    } catch (err) {
      console.error('加载失败', err);
    } finally {
      this.loading = false;             // ② 关掉加载提示
      request.destroy();
    }
  }

  build() {
    Column() {
      if (this.loading) {
        Text('加载中...')               // ③ loading 时显示提示
      } else {
        List() {
          ForEach(this.articles, (title: string) => {
            ListItem() { Text(title).fontSize(16).padding(12) }
          })
        }
      }
    }
  }
}
```

## 五、POST 请求（往服务器发数据）

比如登录、提交表单：

```typescript
const res = await request.request('https://api.example.com/login', {
  method: http.RequestMethod.POST,
  header: { 'Content-Type': 'application/json' },   // 告诉服务器我发的是 JSON
  extraData: JSON.stringify({                        // 请求体
    username: 'xiaoming',
    password: '123456'
  })
});
```

## 六、常见坑

| 坑 | 现象 | 解决 |
|----|------|------|
| 没声明权限 | 请求直接失败 | `module.json5` 加 INTERNET 权限 |
| 接口是 http 不是 https | 被系统拦截 | 让后端上 https，或配置 cleartextTraffic |
| 没解析 JSON | 拿到一堆字符串 | `JSON.parse()` 转对象 |
| 忘了 destroy | 内存泄漏隐患 | `finally` 里销毁 |

## 小结

- 联网三要素：声明权限 → `http.createHttp()` → `request()` 
- 用 `async/await` 写，逻辑从上往下读
- 数据塞进 `@State`，界面自动刷新
- 别忘 `finally` 里 `destroy()`
