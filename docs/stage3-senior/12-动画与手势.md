# 12 动画与手势

> 学习目标：让界面「动起来」「能摸能滑」，告别死板的静态页面。
> 项目实例：`AnimationPage.ets`、`GesturePage.ets`

## 一、两种动画，先分清

| 类型 | 写法 | 适合 |
|------|------|------|
| **属性动画** | 直接改属性，系统自动补中间过程 | 位移、缩放、变色、透明度 |
| **显式动画** | `animateTo()` 包一段代码 | 多个属性一起动、要精确控制时长曲线 |

## 二、属性动画：一行 .animation() 搞定

```typescript
@State scaleValue: number = 1;

Column() {
  Text('点我放大')
    .scale({ x: this.scaleValue, y: this.scaleValue })   // 缩放属性
    .animation({ duration: 300, curve: Curve.EaseOut })   // 变化过程 300 毫秒
    .onClick(() => {
      this.scaleValue = this.scaleValue === 1 ? 1.5 : 1;  // 改数据，自动动画
    })
}
```

**原理**：`.animation()` 是个「监工」，它盯着的属性（这里是 `scale`）一旦变化，不是瞬间跳变，而是用 300 毫秒平滑过渡过去。

常用动画参数：

```typescript
.animation({
  duration: 300,              // 时长（毫秒）
  curve: Curve.EaseInOut,     // 曲线：先慢后快再慢
  delay: 100,                 // 延迟 100 毫秒才开始
  iterations: 3,              // 重复 3 次（-1 是无限循环）
  playMode: PlayMode.Alternate // 来回播放（放大→缩小→放大）
})
```

## 三、显式动画：animateTo 包一批变化

好几个属性想「齐步走」：

```typescript
@State flag: boolean = false;

Button('开始动画').onClick(() => {
  animateTo({ duration: 500, curve: Curve.Spring }, () => {
    this.flag = !this.flag;   // 这一个开关，带动下面一堆属性一起动
  });
})

// 这些属性都跟着 flag 变，且共用同一个动画配置
Column() {
  Text('盒子')
    .width(this.flag ? 200 : 100)
    .height(this.flag ? 200 : 100)
    .backgroundColor(this.flag ? Color.Blue : Color.Gray)
    .rotate({ angle: this.flag ? 45 : 0 })
}
```

## 四、转场动画：组件出现/消失时

```typescript
if (this.show) {
  Text('我来了')
    .transition({ type: TransitionType.Insert, opacity: 0, translate: { x: -100 } })
    .transition({ type: TransitionType.Delete, opacity: 0, translate: { x: 100 } })
}
// 出现时：从左边 100 的位置 + 透明，滑进来
// 消失时：滑向右边 100 + 变透明
```

## 五、手势：识别用户的摸、滑、捏

```typescript
Text('摸我')
  .gesture(
    TapGesture()                          // 点击
      .onAction(() => { console.info('被点了'); })
  )
  .gesture(
    LongPressGesture()                    // 长按
      .onAction(() => { console.info('被长按了'); })
  )
  .gesture(
    PanGesture()                          // 拖动
      .onActionUpdate((event) => {
        // 拖动中：event.offsetX / offsetY 是拖了多远
        this.offsetX = event.offsetX;
        this.offsetY = event.offsetY;
      })
  )
```

做一个「可拖动的悬浮球」：

```typescript
@State posX: number = 0;
@State posY: number = 0;

Column() {
  Column()
    .width(60).height(60)
    .borderRadius(30)
    .backgroundColor(Color.Blue)
    .translate({ x: this.posX, y: this.posY })   // 跟着手指走
    .gesture(
      PanGesture().onActionUpdate((e) => {
        this.posX = e.offsetX;
        this.posY = e.offsetY;
      })
    )
}
```

## 六、手势 + 动画组合拳

拖动松手后自动弹回原位：

```typescript
.gesture(
  PanGesture()
    .onActionUpdate((e) => {
      this.posX = e.offsetX;   // 跟着手指（无动画，跟手）
    })
    .onActionEnd(() => {
      animateTo({ duration: 300, curve: Curve.Spring }, () => {
        this.posX = 0;         // 松手弹回去（弹簧曲线）
        this.posY = 0;
      });
    })
)
```

## 七、性能提醒

- 动画属性优先用 `translate`/`scale`/`rotate`/`opacity`——它们最流畅（走 GPU）
- 少用动画改 `width`/`height`——会触发重新布局，容易卡
- 列表项里的动画要克制，一屏几十个项目一起动会掉帧

## 动手练

1. 做一个「点赞按钮」：点击时爱心放大到 1.3 倍再弹回（用 `animateTo` + 弹簧曲线）。
2. 做一个「下拉刷新」的雏形：监听下拉手势，下拉超过 100 就触发刷新动画。

## 小结

- 单个属性变 → `.animation()`；一批属性齐动 → `animateTo()`
- 手势三兄弟：`TapGesture` 点、`LongPressGesture` 长按、`PanGesture` 拖
- 手势负责「跟手」，动画负责「收尾」，组合起来手感才好
