# 10 本地存储与数据库

> 学习目标：把数据存在手机里，关掉 App 再打开还在。
> 项目实例：`StoragePage.ets`、`DatabasePage.ets`

## 一、三种存储方式，怎么选

| 方式 | 存什么 | 类比 | 例子 |
|------|--------|------|------|
| **AppStorage** | 内存里的全局数据 | 白板，擦了就没了 | 状态栏高度、当前主题 |
| **Preferences** | 少量简单配置 | 小本子 | 用户设置、登录 token |
| **关系型数据库** | 大量结构化数据 | Excel 表格 | 聊天记录、商品列表 |

**选择口诀**：临时共享用 AppStorage，简单配置用 Preferences，成堆数据用数据库。

## 二、AppStorage：全局内存（重启就没了）

```typescript
// 存（任何地方都能存）
AppStorage.setOrCreate('username', '小明');

// 取（组件里自动绑定，值变了界面自动刷新）
@StorageProp('username') username: string = '';
```

项目实例：`EntryAbility.ets` 把状态栏高度存进 AppStorage，所有页面用 `@StorageProp` 读。

## 三、Preferences：键值对持久化（最常用）

适合存「设置项」「上次登录的账号」这种简单数据。

```typescript
import { preferences } from '@kit.ArkData';

// ① 拿到一个 Preferences 实例（context 在页面里用 getContext(this) 获取）
const store = preferences.getPreferencesSync(getContext(this), { name: 'my_settings' });

// ② 存
store.putSync('dark_mode', true);
store.flush();   // 别忘了刷到磁盘，否则可能丢

// ③ 取（第二个参数是"取不到时的默认值"）
const isDark = store.getSync('dark_mode', false);

// ④ 删
store.deleteSync('dark_mode');
```

**键值对**就是「名字 → 值」的一对一关系，像字典：`'dark_mode' → true`。

## 四、实战：记住用户的开关状态

```typescript
@Entry
@Component
struct SettingsPage {
  @State darkMode: boolean = false;
  private store = preferences.getPreferencesSync(getContext(this), { name: 'my_settings' });

  aboutToAppear(): void {
    // 页面打开时，读上次存的值
    this.darkMode = this.store.getSync('dark_mode', false) as boolean;
  }

  build() {
    Column() {
      Row() {
        Text('深色模式')
        Toggle({ isOn: this.darkMode })
          .onChange((isOn: boolean) => {
            this.darkMode = isOn;
            this.store.putSync('dark_mode', isOn);   // 改了就存
            this.store.flush();
          })
      }
    }
  }
}
```

这样用户关掉 App 再打开，开关还是上次的状态。

## 五、关系型数据库（数据多了再用）

存聊天记录、订单这种「一行一行」的数据，用 SQLite 数据库：

```typescript
import { relationalStore } from '@kit.ArkData';

// ① 建库（拿到 store 对象）
const storeConfig: relationalStore.StoreConfig = {
  name: 'demo.db',
  securityLevel: relationalStore.SecurityLevel.S1
};
const store = await relationalStore.getRelationalStore(getContext(this), storeConfig);

// ② 建表（SQL 语句，第一次运行时执行）
await store.executeSql(`
  CREATE TABLE IF NOT EXISTS note (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    content TEXT,
    create_time INTEGER
  )
`);

// ③ 增：插入一行
const bucket: relationalStore.ValuesBucket = {
  'title': '第一条笔记',
  'content': '内容内容',
  'create_time': Date.now()
};
await store.insert('note', bucket);

// ④ 查：按条件查询
const predicates = new relationalStore.RdbPredicates('note');
predicates.orderByDesc('create_time');   // 按时间倒序
const resultSet = await store.query(predicates);
while (resultSet.goToNextRow()) {
  const title = resultSet.getString(resultSet.getColumnIndex('title'));
  console.info('笔记：' + title);
}
resultSet.close();   // 用完关闭

// ⑤ 改 / 删
predicates.equalTo('id', 1);
await store.update(bucket, predicates);   // 改 id=1 的行
await store.delete(predicates);           // 删 id=1 的行
```

> SQL 不熟没关系，先记住「建表、增、查、改、删」五个动作，语句照抄改表名和字段名。

## 六、常见坑

| 坑 | 解决 |
|----|------|
| `putSync` 后没 `flush()` | 数据可能没写盘，养成「改完就 flush」的习惯 |
| context 拿不到 | 页面里用 `getContext(this)` |
| 数据库字段类型写错 | TEXT 存字符串，INTEGER 存数字 |
| 查询完没 close | `resultSet.close()` 释放资源 |

## 动手练

1. 给「意见反馈页」加功能：提交的内容先用 Preferences 存一份草稿，下次打开自动填回。
2. 用数据库做一个「备忘录」：能新增、列表显示、左滑删除。

## 小结

- 临时共享 → AppStorage；简单配置 → Preferences；成堆数据 → 数据库
- Preferences 三步：`putSync` 存 → `flush` 刷盘 → `getSync` 取
- 数据库五动作：建表、增（insert）、查（query）、改（update）、删（delete）
